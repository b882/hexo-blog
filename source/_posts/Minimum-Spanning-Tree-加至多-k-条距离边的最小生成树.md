## 题意

给定一张 `n` 个点、`m` 条边的无向连通图，允许再加入至多 `k` 条边；若加入的边连接 `u` 和 `v`，它的权值就是 `|u-v|`。要求加边后整张图最小生成树的最小总权值，并输出完整方案：加哪些边、最小生成树的总权值、以及构成这棵生成树的 `n-1` 条边（原边用输入编号 `1..m`，新加的第 `j` 条边编号为 `m+j`）。

图保证连通，允许多重边和自环；所有测试点的 `n`、`m`、`k` 之和都不超过 `2×10^5`，单组时限 3 秒。

## 核心思路

关键是把「加一条长边」这件事归约掉。

设最优方案加入了 `c` 条新边。把这 `c` 条新边从生成树里删掉，原边就被分成 `c+1` 个连通块。注意顶点编号天然构成一条链 `1-2-…-n`，链是连通的：只要把这 `c+1` 个连通块沿链依次接起来，恰好需要 `c` 条形如 `(i, i+1)` 的边，每条权值都是 `1`。

替换不会让答案变大：原来 `c` 条新边的权值和至少是 `c`（因为每条 `|u-v| ≥ 1`），替换后正好是 `c`；加边条数也没变，仍然是 `c ≤ k`。

所以可以假设：**最优解里的新边全部是 `(i, i+1)`，权值都是 1**。

于是方案等价于：先选一个只由原边组成的森林 `F`，剩下 `n-1-|F|` 个连通块用相邻单位边补齐，补边数 `c = n-1-|F|` 必须满足 `c ≤ k`，即 `|F| ≥ n-1-k`。总代价

```text
Σ w(e) + (n-1-|F|) = (n-1) + Σ (w(e) - 1)
```

每条原边在目标里的「修正代价」变成了 `w(e)-1`：

- `w = 0`：修正代价 `-1`，能加就加；
- `w = 1`：修正代价 `0`，加了不亏，还能帮忙凑够边数；
- `w ≥ 2`：修正代价为正，只有在边数不足 `n-1-k` 时才不得不加。

这就是按 `w` 升序做 Kruskal 时的取舍规则。

## 算法设计

1. 原边按权值升序排序，结构体里记下输入编号 `id`。
2. 并查集维护连通性，记已选边数 `num`、答案 `ans`：
   - 依次扫描排好序的边，若它连接两个不同连通块，且满足 `num < n-1-k` **或** `w <= 1`，就选中：`num++`、`ans += w`、记录原边编号。
   - `num == n-1` 时提前结束。
   - 条件 `num < n-1-k` 的含义是：原边至少要有 `n-1-k` 条，剩下至多 `k` 条交给新边；一旦条数够了，就只接受修正代价非正（`w ≤ 1`）的边。
3. 补边阶段：`i` 从 `1` 扫到 `n-1`，若 `i` 与 `i+1` 还不在同一连通块，就加入新边 `(i, i+1)`，权值 `1`，编号为 `m + 已加新边数`，直到 `num == n-1`。
4. 输出：新边条数与端点、总权值，以及 `n-1` 条树边的编号。

由于链图连通，补边阶段一定能把所有连通块并成一棵生成树，且补边数不超过 `k`。

## 正确性说明

**引理 1（新边可以只取相邻边）**：对任意新边集合 `S`（`|S| ≤ k`），把生成树里的 `S` 删掉得到 `|S|+1` 个连通块。链图连通，对这 `|S|+1` 个连通块在链上做一次 Kruskal，恰好用 `|S|` 条相邻边就能把它们重新连成一棵树；新边权值和从 `Σ|u-v| ≥ |S|` 降为 `|S|`，加边条数不变。所以存在只用相邻单位边的最优解。

**引理 2（代价公式）**：只用相邻单位边时，方案由原边森林 `F` 唯一决定：补边数 `c = n-1-|F|`，总代价为 `(n-1) + Σ(w(e)-1)`，可行当且仅当 `|F| ≥ n-1-k`。

**引理 3（贪心最优）**：把原边权值看成 `w(e)-1`，要选出一个森林、边数不少于 `L = n-1-k`，并使总权值最小，按 `w` 升序的 Kruskal 加配额就是最优：

- `w = 0` 的边权值为负，Kruskal 取到这张子图的最大森林，负权边取得最多；
- `w = 1` 的边权值为 `0`，取它不增加代价，还能让 `|F|` 变大；而图连通，任何森林都能补成生成树，多取一条零代价边不会让后面更难满足下界，所以应尽量取；
- 其余边权值为正，只在下界还差边时才需要，按权值从小到大取最便宜的即可。

算法恰好按 `w` 升序、在「不足 `L` 条」或「`w ≤ 1`」时接收边，得到的森林满足上述最优性条件。

**定理**：算法输出的总权值就是最小总权值；补边数 `c = n-1-|F| ≤ k`（第一阶段结束时 `|F| ≥ min(n-1, n-1-k)`）；输出的 `n-1` 条边互不相同，且在原边加新边的图上构成一棵生成树。

## 复杂度分析

每组数据时间 `O(m log m + n α(n))`，空间 `O(n+m)`。由于所有测试点的 `Σn, Σm, Σk ≤ 2×10^5`，总复杂度 `O((Σm) log(Σm))`，可以轻松通过。

## 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ll long long
#define ALL(x) (x).begin(),(x).end()
struct Edge{
	int u,v,id;
	ll w;
};
bool cmp(Edge a,Edge b){
	return a.w<b.w;
}
struct DSU{
	vector<int> f,sz;
	DSU(int n) : f(n),sz(n,1){
		iota(ALL(f),0);
	}
	int find(int x){
		return f[x] == x ? x : f[x]=find(f[x]);
	}
	bool merge(int a,int b){
		a=find(a);
		b=find(b);
		if(a==b) return 0;
		if(sz[a]<sz[b]) swap(a,b);
		f[b]=a;
		sz[a]+=sz[b];
		return 1;
	}
};

int main(){
	ios::sync_with_stdio(false);	
	cin.tie(nullptr);
	int t;
	cin>>t;
	while(t--){
		int n,m,k;
		cin>>n>>m>>k;
		vector<Edge> mp(m+1);
		for(int i=1;i<=m;i++){
			cin>>mp[i].u>>mp[i].v>>mp[i].w;
			mp[i].id=i;
		}
		sort(mp.begin()+1,mp.end(),cmp);
		DSU dsu(n+1);
		int num=0;
		ll ans=0;
		vector<int> ansss;
		
		for(int i=1;i<=m;i++){
			if(num==n-1){
				break;
			}
			if(num<n-1-k || mp[i].w<=1){
				if(dsu.merge(mp[i].u,mp[i].v)==1){
					num++;
					ans+=mp[i].w;
					ansss.push_back(mp[i].id);
				}
			}
		}
		vector<pair<int,int> > anss;
		int bnum=num;
//		cout<<ans<<endl;
		for(int i=1;i<n;i++){
			if(num==n-1){
				break;
			}
			if(dsu.merge(i,i+1)==1){
				num++;
				anss.push_back({i,i+1});
				ansss.push_back(num-bnum+m);
				ans+=1;
			}
		}
		cout<<anss.size()<<"\n";
		for(int i=0;i<anss.size();i++){
			cout<<anss[i].first<<' '<<anss[i].second<<"\n";
		}
		cout<<ans<<'\n';
		for(int i=0;i<ansss.size();i++){
			cout<<ansss[i]<<' ';
			
		}
		cout<<'\n';
	}
	
	
	return 0;
}
```

## 易错点

- 输出的是 `n-1` 个**边编号**，不是顶点对；原边按输入顺序编号 `1..m`，新边从 `m+1` 开始编号，顺序任意但不能重复。
- 新边只需要输出两个端点，权值由 `|u-v|` 自动决定，不要额外输出权值。
- `k` 可能大于 `n-1`：此时 `n-1-k < 0`，第一阶段只接受 `w ≤ 1` 的边，补边数依然不超过 `n-1 ≤ k`。
- 答案要用 `long long`：最坏情况约 `2×10^5 × 10^9 = 2×10^14`。
- 多组数据要清空并查集、`ans` 和两个编号数组；自环 `u = v` 会被 `merge` 直接跳过，重边正常处理。
- 树边输出顺序不要求与题面样例一致，只要集合相同、能构成生成树即可。

## 本地验证记录

以下是本地自测结论，不是评测机结果：

- 题面样例 3 组：总权值分别为 `6`、`1`、`200`，与样例输出一致；第一组的树边集合与样例相同（`{1,6,7,8}`），只是输出顺序不同。
- 与暴力对拍：`n ≤ 6`，枚举所有不超过 `k` 条的加边子集并重新求最小生成树，共 600 组随机数据，答案与方案合法性（条数、编号、连通性、权值和）全部一致。
- 极限数据：单组 `n = m = 2×10^5`、`k = 10^5`，本机 MinGW g++ 13.2、`-O2` 约 0.13 秒；`T = 10^4` 的小数据约 0.05 秒。
