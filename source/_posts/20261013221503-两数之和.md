## 题目描述

给定两个整数a和b，输出它们的和。

<!-- more -->

## 解题思路

直接读取两个整数并输出它们的和。

## C++ 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int a,b;
    cin>>a>>b;
    cout<<a+b;
    return 0;
}
```
